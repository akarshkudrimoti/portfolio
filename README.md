# Matrix Terminal Portfolio

A Next.js portfolio with a Matrix-inspired terminal interface.

## Features

- Interactive terminal interface with command support
- Project showcase with detailed descriptions
- Face authentication simulation
- Responsive design

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment

This project is configured for deployment to GitHub Pages using GitHub Actions. Simply push to the main branch to trigger the deployment workflow.

## Technologies Used

- Next.js
- TypeScript
- xterm.js
- Three.js
- Tailwind CSS
